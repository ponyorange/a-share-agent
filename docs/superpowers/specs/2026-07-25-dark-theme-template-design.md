# 深色配色模板（深海蓝）增量设计

日期：2026-07-25

基于：`docs/superpowers/specs/2026-07-25-account-theme-settings-design.md`

## 目标

在现有账号级配色设置上新增第三套模板「深海蓝」，供用户在浅色模板之外切换到深色界面：

- 涨跌语义延续「现代数据」：蓝色上涨、琥珀色下跌。
- 仍开放相同的十个语义色，用户可自定义并保存到账号。
- 默认主题不变，仍为浅色「现代数据」。
- 深色模板下不出现固定浅色亮块。

## 范围

### 包含

- 新增模板 ID `deep_navy`，前后端同步允许。
- 设置页模板选择区增加「深海蓝」。
- 将固定浅色辅助背景改为由 `page_bg` 与 `surface` 派生，确保深浅模板均可工作。
- 扩展模板相关测试与验收。

### 不包含

- 第二套深色行情模板（红涨绿跌）。
- 独立的深色模式开关或系统偏好自动切换。
- 新增第 11 个用户可编辑色值。
- 迁移或改写用户已保存的浅色主题。
- 重做整体布局或组件结构。

## 模板色值

### 深海蓝 `deep_navy`

| 语义 | 字段 | 色值 |
|---|---|---|
| 页面背景 | `page_bg` | `#101724` |
| 卡片背景 | `surface` | `#192335` |
| 主文字 | `text_primary` | `#F2F5FA` |
| 次文字 | `text_muted` | `#99A7BB` |
| 边框 | `border` | `#303E55` |
| 品牌主色 | `brand` | `#8793FF` |
| 上涨 | `market_up` | `#70A9F8` |
| 下跌 | `market_down` | `#F1B85B` |
| 成功 | `success` | `#61C28F` |
| 错误 | `error` | `#F17C8E` |

选择理由：与浅色「现代数据」共享蓝紫品牌家族，蓝涨琥珀跌保持弱金融语义，深色下仍保有可读对比度。

## 数据与 API

- `ThemeId` / `THEME_IDS` / Pydantic `Literal` 扩展为：
  - `modern_data`
  - `classic_market`
  - `deep_navy`
- 后端 `DEFAULT_THEMES` 与前端 `THEME_TEMPLATES` 增加 `deep_navy` 默认色。
- 存储格式不变：仍保存 `active_template` + 完整十色。
- 未配置用户仍返回 `modern_data` 默认设置，不写库。
- 已保存浅色主题无需迁移；用户显式切换并保存后才会变成 `deep_navy`。
- 非法模板 ID 仍返回 422 / 服务层 `ValueError`。

## 前端交互

- 设置页模板卡片增加「深海蓝」。
- 切换行为与现有一致：有未保存修改时确认覆盖；确认后载入该模板默认色；保存后才写后端。
- 「恢复模板默认值」在当前模板为 `deep_navy` 时恢复上述深色默认值。
- 实时预览继续使用局部 CSS 变量，不提前应用全局主题。
- 对比度警告规则不变：只警告，不阻止保存。

## CSS 兼容

当前若干样式依赖固定浅色辅助色，例如 `--bg2: #f0f2f7` 与 body 渐变中的 `#f0f2f7`。深色模板启用后会出现亮色块。

处理方式：

1. 新增派生 token `--color-surface-muted`，按页面明度自适应计算：
   - 浅色：`page_bg` 向 `text_primary` 混合 4%，得到略深于页面的浅灰面板。
   - 深色：`page_bg` 向 `surface` 混合 55%，得到介于页面与卡片之间的暗面。
2. `applyTheme` 计算并写入该派生值；`:root` 默认值为现代数据对应的 `rgb(238, 239, 244)`。
3. 将 `--bg2` 与 body 渐变中的硬编码 `#f0f2f7` 替换为 `--color-surface-muted`。
4. 不把该派生色暴露为第 11 个用户可编辑字段。

## 错误处理

- 后端拒绝未知模板 `deep_navy` 以外的新 ID。
- 前端缓存校验同步接受 `deep_navy`；旧缓存中的未知模板仍按非法设置回退。
- 加载失败、保存失败、对比度警告行为与原设计一致。

## 测试

- 后端：`deep_navy` 可保存；未知模板仍拒绝；默认仍为 `modern_data`。
- 前端：三套模板均含且仅含十色；设置页可选择「深海蓝」；恢复默认值回到深海蓝默认色。
- `applyTheme(deep_navy)` 写入深色基础色与 `--color-surface-muted`。
- 回归：浅色两套模板、账号同步、登出恢复默认、涨跌/成功/错误语义不串色。

## 验收标准

- 设置页可见三套模板：现代数据、经典行情、深海蓝。
- 选择深海蓝后，预览与保存应用呈现深色页面与卡片。
- 涨为蓝、跌为琥珀；成功与错误色独立可读。
- 深色主题下无明显固定浅色亮块。
- 未保存用户默认仍为浅色现代数据。
- 已保存浅色主题的用户刷新后仍保持原设置，除非主动切换并保存深海蓝。
