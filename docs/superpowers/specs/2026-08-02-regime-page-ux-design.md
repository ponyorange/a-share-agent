# 今日闸门页可读性改版（纯前端）

日期：2026-08-02  
状态：已确认设计（待用户审阅 spec 正文）

## 目标

把顾问前端「市场状态」改成用户一眼能懂的 **「今日闸门」**：先回答能不能干、干多大，再给三句人话理由；专业字段默认不抢视线。

## 已确认决策

| 项 | 决策 |
|----|------|
| 信息架构 | 决策优先（结论 → 仓位 → 一句话 → 三标签 → 为什么） |
| 导航 / 页面标题 | **今日闸门**（路由仍为 `/regime`） |
| 「为什么」深度 | 最多 3 句人话；指标明细默认折叠 |
| 实现路线 | 方案 1：纯前端映射现有 API，不改闸门引擎 |

## 非目标

- 不改 `MarketRegime` 计算、半硬闸门逻辑、Mongo 归档语义
- 本版不增加后端 `headline` / `why_bullets` 字段
- 不重做打板主表（仅情绪条白话与链接触达）
- 不改 Agent 工具返回结构（Agent 仍读原字段）

## 首屏信息架构

从上到下：

1. 标题：今日闸门  
2. 结论行：白话动作 + 建议总仓位上限（`position_cap` → 百分整数）  
3. 一句话：由闸门 + 趋势 + 情绪拼出的短解释  
4. 三标签：趋势 / 情绪 / 数据（全中文）  
5. 「为什么这样判」：≤3 条人话  
6. 操作：`risk_off` 时「仍要看今日关注」→ `/?regime_override=1`；否则次要「查看今日关注」→ `/`  
7. 折叠区（默认收起）：「查看指标明细」→ evidence / 关键 metrics，中文列名  
8. 近几日：日期 + 中文闸门名 + 仓位（不展示英文枚举）

## 文案映射

### 闸门 → 结论 / 一句话

| `gate_level` | 结论 | 一句话模板 |
|--------------|------|------------|
| `aggressive` | 可以积极一点 | 趋势与情绪都偏强，可按上限内正常参与，仍控制单票风险。 |
| `normal` | 正常参与即可 | 市场中性偏稳，按计划交易即可，不必追也不必空仓。 |
| `defensive` | 先轻仓观望 | 赚钱效应转弱或结构一般，先降仓位、少开新仓。 |
| `risk_off` | 今天先别急着买 | 环境偏危险，默认不推新买入；守住现金与持仓风控更重要。 |

仓位文案：`建议总仓位不超过 {N}%`（`N = round(position_cap * 100)`）。

### 三标签

| 字段 | 展示名 | 值映射 |
|------|--------|--------|
| `trend_regime` | 趋势 | uptrend→上行；range→震荡；downtrend→下行 |
| `sentiment_cycle` | 情绪 | ice→冰点；repair→修复；strengthen→增强；climax→高潮；ebb→退潮 |
| `data_quality` | 数据 | ok→可用；degraded→部分缺失（已偏保守）；failed→暂不可靠（请降仓） |

禁止在首屏展示：`raw gate_level`、英文枚举、`pool_policy` 原文。

### 「为什么这样判」生成规则

输入：`evidence[]`、常用 `metrics`、当前 `gate_level` / `trend_regime` / `data_quality`。  
输出：字符串数组，长度 1～3。

优先级：

1. 带可读 `note` 的 evidence → 用人话 note（约 ≤28 字）  
2. 否则按 key / 指标映射，例如：  
   - 涨停偏少 / 封板率偏低 → 「涨停变少，赚钱效应转弱」  
   - 高度或晋级偏弱 → 「连板高度或晋级回落，接力变难」  
   - 趋势下行或震荡 → 「指数偏弱或震荡，不宜重仓」  
3. 不足 3 条时用闸门兜底句补齐  
4. 若 `data_quality !== "ok"`，三条中至少一条说明数据降级 / 已偏保守  

### 折叠明细

默认收起。展开表格列：指标（中文）/ 数值 / 说明。  
比率类字段按小数比例格式化为百分数（与产品约定一致：`0.40` → `40%`）。

## 联动

- 打板页情绪条：同一套情绪中文映射；入口文案「查看今日闸门」→ `/regime`  
- 今日关注：闸门角标用中文结论或闸门中文名，不露英文枚举  
- Override 行为与现网一致，仅文案/展示优化

## 验收标准

1. 首屏无英文 `gate_level` / `trend_regime` / `sentiment_cycle` / `data_quality` raw 展示  
2. 可见：结论、仓位上限、一句话、三标签、≤3 条「为什么」  
3. 指标明细默认折叠；展开后为中文列名  
4. 导航与 H1 为「今日闸门」；历史区中文闸门名  
5. `risk_off` 仍有「仍要看今日关注」且跳转 `/?regime_override=1`  
6. 更新后的 RegimePage / TopbarNav 等相关测试通过  

## 风险

| 风险 | 缓解 |
|------|------|
| 人话映射与真实指标偶尔不完全贴合 | 优先用 evidence.note；映射表可单测 |
| 路由仍叫 `/regime` 略抽象 | 导航与 H1 已改；外链不破 |
| Agent 与页面话术不完全一致 | 接受为本版非目标；后续可加后端摘要字段 |
