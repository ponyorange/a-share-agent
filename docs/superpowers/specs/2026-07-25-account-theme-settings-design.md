# 账号级浅色配色设置设计

日期：2026-07-25

## 目标

为 `frontend-advisor` 增加账号级配色设置：

- 整个应用统一使用浅色主题，包括基础面板和 Agent 面板。
- 提供两套预设模板：
  - 「现代数据」：蓝色代表上涨，琥珀色代表下跌，弱化股市视觉特征。
  - 「经典行情」：红色代表上涨，绿色代表下跌，符合 A 股惯例。
- 用户可在模板基础上修改所有开放的语义色。
- 后端按账号保存当前模板和完整色值，用户更换浏览器或设备后仍能同步。
- 配色对比度不足时给出警告，但不阻止保存。

## 范围

### 包含

- 基础面板新增「设置」导航与 `/settings` 页面。
- 两套浅色模板及模板切换。
- 十个开放的语义色编辑项。
- 实时预览、对比度警告、恢复模板默认值、保存并应用。
- 前后端账号级配色读取与更新 API。
- 整理现有 CSS 颜色语义，分离品牌色、涨跌色和状态色。
- 登录、刷新和跨设备场景下的主题同步。

### 不包含

- 深色模式。
- 用户创建、命名和保存多套自定义主题。
- 主题历史或版本回滚。
- 管理员统一下发主题。
- 阻止用户保存低对比度配色。

## 交互设计

### 设置页

设置页沿用现有基础面板页面结构，包含：

1. 模板选择区
   - 「现代数据」和「经典行情」以卡片形式展示。
   - 卡片显示上涨、下跌和品牌色的色块。
   - 切换模板前提示当前自定义修改将被覆盖。
   - 确认后将编辑器替换为目标模板的默认色，但在用户点击保存前不写入后端。

2. 自定义颜色区
   - 每项同时提供原生颜色选择器和十六进制文本输入。
   - 十六进制输入统一规范为 `#RRGGBB`。
   - 开放以下十个语义色：
     - 页面背景 `page_bg`
     - 卡片背景 `surface`
     - 主文字 `text_primary`
     - 次文字 `text_muted`
     - 边框 `border`
     - 品牌主色 `brand`
     - 上涨 `market_up`
     - 下跌 `market_down`
     - 成功 `success`
     - 错误 `error`

3. 实时预览区
   - 预览导航、卡片、主次文字、上涨/下跌、成功/错误等核心状态。
   - 编辑颜色时仅更新预览草稿，不立即影响整个应用，避免未保存的不可读主题干扰设置操作。

4. 操作区
   - 「恢复模板默认值」：恢复当前模板默认颜色，仅更新草稿。
   - 「保存并应用」：更新后端，成功后将主题应用到整个应用并更新本地缓存。

### 对比度提示

- 使用 WCAG 相对亮度算法检查关键组合。
- 至少检查：
  - 主文字与页面背景。
  - 主文字与卡片背景。
  - 次文字与页面背景。
  - 次文字与卡片背景。
  - 品牌色与卡片背景。
  - 上涨、下跌、成功、错误色与其显示背景。
- 普通文字目标对比度为 4.5:1，大号文字目标为 3:1。
- 不达标时在对应字段附近和设置页顶部显示警告。
- 警告不阻止保存，符合用户选择的宽松策略。

## 前端架构

### 主题模块

新增独立主题模块，职责为：

- 定义主题 ID、颜色字段和 API 数据类型。
- 提供两套不可变模板默认值。
- 校验并规范十六进制颜色。
- 将语义色转换为 CSS 自定义属性。
- 生成透明背景等派生色，避免后端保存重复数据。
- 读写按用户隔离的浏览器缓存。
- 计算对比度警告。

后端只保存十个基础语义色。以下派生值由前端计算：

- 品牌柔和背景。
- 上涨和下跌柔和背景。
- 成功和错误柔和背景。
- hover、focus ring、渐变和阴影所需的透明色。

### CSS 语义解耦

现有 `--accent` 和 `--sell` 同时承担品牌、涨跌、成功和操作状态，必须先拆分：

- `--color-page-bg`
- `--color-surface`
- `--color-text-primary`
- `--color-text-muted`
- `--color-border`
- `--color-brand`
- `--color-brand-soft`
- `--color-market-up`
- `--color-market-up-soft`
- `--color-market-down`
- `--color-market-down-soft`
- `--color-success`
- `--color-success-soft`
- `--color-error`
- `--color-error-soft`

组件和样式按语义引用，不再使用品牌色表示上涨，也不再使用下跌色表示成功。

买入、卖出等操作标签不直接等同于涨跌状态。它们使用品牌色、错误色或专用派生样式，保证切换至现代数据模板后不会残留红绿股市语义。

### 启动与同步

为兼顾跨设备同步和首屏无闪烁：

1. 应用启动前读取按用户 ID 隔离的本地主题缓存并立即应用。
2. 登录校验成功后请求后端 UI 设置。
3. 请求成功时以后端数据覆盖本地缓存和当前主题。
4. 账号没有设置时使用「现代数据」默认模板，并允许后端在首次读取时返回默认值。
5. 请求失败时继续使用缓存或默认模板，不阻断应用。
6. 保存成功后同时更新当前主题和本地缓存。
7. 退出登录时移除当前页面上的用户主题，回到默认模板，避免不同账号间短暂串色。

缓存 key 必须包含用户 ID，不能只使用全局主题 key。

## 后端设计

### 存储

新增 MongoDB 集合 `user_ui_settings`，每个用户一条文档：

```json
{
  "user_id": "用户 ID",
  "active_template": "modern_data",
  "colors": {
    "page_bg": "#F6F7FB",
    "surface": "#FFFFFF",
    "text_primary": "#273247",
    "text_muted": "#778195",
    "border": "#E5E8F1",
    "brand": "#6673D9",
    "market_up": "#3568B8",
    "market_down": "#A96918",
    "success": "#377659",
    "error": "#A84C5B"
  },
  "created_at": "UTC 时间",
  "updated_at": "UTC 时间"
}
```

为 `user_id` 创建唯一索引。沿用项目现有 `ensure_indexes()` 和 per-user upsert 模式，不引入新的迁移框架。

`active_template` 记录用户最后选择的模板，即使颜色已被自定义也保留其起点信息。它只允许：

- `modern_data`
- `classic_market`

### API

新增以下鉴权接口：

- `GET /api/advisor/ui/settings`
  - 有记录时返回完整设置。
  - 无记录时返回「现代数据」默认设置，不强制写库。

- `PUT /api/advisor/ui/settings`
  - 接收 `active_template` 和完整 `colors`。
  - 校验字段完整、模板 ID 合法以及颜色符合 `#RRGGBB`。
  - 不执行对比度拒绝。
  - 使用 `user_id` upsert，并返回规范化后的完整设置。

禁止客户端提交额外颜色字段，避免任意 CSS 属性注入。

## 错误处理

- 初次加载失败：使用用户本地缓存；无缓存时使用现代数据模板，并显示非阻断提示。
- 保存失败：保留编辑草稿和原已应用主题，不更新缓存。
- 后端返回缺失或非法字段：视为无效设置，回退缓存或默认模板，并记录错误。
- 输入非法十六进制值：字段内提示，禁止提交；这属于数据格式错误，不是对比度限制。
- 模板切换：存在未保存修改时必须二次确认。
- 网络请求竞态：只应用最近一次加载或保存结果，避免旧响应覆盖新主题。

## 测试

### 前端

- 两套模板包含且只包含十个必需颜色字段。
- 十六进制规范化、非法输入和派生透明色计算。
- WCAG 对比度计算及只警告、不阻止保存。
- 设置页加载、编辑、实时预览、恢复模板、切换确认和保存。
- 保存失败时保留草稿且不改变已应用主题。
- 登录加载、缓存回退、退出恢复默认和不同用户缓存隔离。
- CSS 语义映射确保 `.up`、`.down`、成功和错误状态互不串色。
- 基础面板和 Agent 面板均应用同一主题。

### 后端

- 未配置用户获得现代数据默认设置。
- 用户只能读取和更新自己的设置。
- PUT 完整 upsert 并规范化颜色。
- 缺字段、额外字段、非法模板和非法颜色返回 422。
- 低对比度配色可以正常保存。
- `user_id` 唯一索引及重复更新行为。

### 回归

- 登录、退出及 `/api/auth/me` 流程不受影响。
- 基础面板和 Agent 面板导航、按钮、表格、卡片、聊天和投委会状态均可读。
- 上涨/下跌颜色在两套模板中符合定义。
- 现有移动端布局不因新增设置入口和颜色控件溢出。

## 验收标准

- 新用户首次进入时看到浅色「现代数据」模板。
- 用户可切换至「经典行情」，并看到红涨绿跌。
- 用户可修改十个语义色，低对比度仅收到警告。
- 保存后整个应用立即应用新主题。
- 刷新、重新登录或在另一设备登录后可恢复账号主题。
- 切换模板会在确认后覆盖当前草稿。
- 恢复默认值只恢复当前模板，保存后才写入后端。
- 品牌、涨跌、成功和错误状态拥有独立颜色语义。
