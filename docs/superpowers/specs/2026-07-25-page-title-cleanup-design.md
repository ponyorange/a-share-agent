# 页面标题精简设计

## 目标

降低桌面端品牌标题的视觉权重，并移除与顶部导航重复的业务页面一级标题，减少重复信息。

## 设计

1. 仅在桌面端断点缩小顶部左侧 `.brand`“次日顾问”的字号；移动端保持现状。
2. 删除已登录业务页面 `.page-hero` 中与导航重复的 `<h1>`，保留其说明文字、操作、摘要和状态内容。
3. 登录页 `<h1>次日顾问</h1>` 保留，因为它承担产品身份标识，不是导航重复标题。
4. 页面内部用于内容分组的二级标题继续保留，例如“持仓”“成交记录”“颜色编辑”。
5. Agent 与基础面板采用同一规则，包括“Agent 设置”“策略副驾”“知识库”等页面级标题。

## 可访问性

删除视觉重复的一级标题后，页面仍由路由、导航当前态、说明文字及内部语义化分区表达结构。现有表单、区域标签和二级标题不变。

## 验证

- 回归测试确认业务页面不再渲染对应一级标题。
- 登录页仍显示“次日顾问”一级标题。
- 桌面端 `.brand` 字号缩小，移动端规则不变。
- 前端完整测试、lint 和构建通过。
