# 模拟盘交易员驾驶舱布局修订

## 目标

1. 将 `/paper/trader` 从失衡的双栏改为**三栏终端感**布局，一屏可读候选、日 K/决策、持仓与今日统计。
2. 修复日 K **选中后仍空白**（图表容器未挂载导致未初始化）。
3. 限制各区高度并内部滚动，避免候选表把页面拉飞。

## 已确认决策

| 项 | 决策 |
|----|------|
| 版式 | **C 三栏**：左候选 \| 中日 K + 决策 \| 右持仓 + 今日统计 |
| 桌面比例 | 约 26% / 48% / 26% |
| 窄屏 | &lt;1100px 单列：候选 → K/决策 → 持仓 |
| 范围 | 仅前端结构 + CSS + `PaperTraderChart` 初始化修复；API/轮询/启停语义不变 |
| 视觉 | 细边框/分区背景，贴合现有 advisor 风格；不新做皮肤体系 |

## 非目标

- 改 cockpit API 或 worker 决策逻辑
- 分钟线、多图联动、完整复刻 `/paper` 下单 UI
- Visual Companion / 新依赖（除已有 lightweight-charts）

## 布局

### 桌面

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：标题 · 状态 · 净值 · 启停 · 模拟盘链接                  │
│ 模式与风控（折叠）                                           │
├────────────┬─────────────────────────────┬───────────────────┤
│ 候选池     │ 日 K（固定高度）              │ 迷你持仓          │
│ 限高滚动   │ 决策时间线（K 下可滚）        │ 今日轮次/成交/拦截│
│ ~26%       │ ~48%                        │ ~26%              │
└────────────┴─────────────────────────────┴───────────────────┘
```

### 行为要点

- 三栏舱体等高（或 `align-items: stretch`）；各面板 `min-height: 0`，列表 `overflow: auto`。
- 候选表：`max-height`（如 `min(52vh, 28rem)`）内滚动；行点击仍选中标的。
- 中栏：K 线 host 固定高度（约 280–320px）；决策列表限高滚动，展开详情仍用现有 JSON。
- 右栏：持仓列表可点选标的；底部展示 `stats_today`（轮次/成交/拦截）。
- 顶栏与「模式与风控」位置与语义保持不变。

## 图表修复

`PaperTraderChart`：

- **始终**渲染 chart host（无 `symbol` 时 host 可空数据 + 占位文案叠加）。
- `createChart` 在 host 已挂载后执行；`symbol` 变化只 `setData` / 重新请求，不依赖「首次就有 symbol」。
- resize 仍绑定 host `clientWidth`。

## 验收

1. 有候选时：三栏对齐，候选过长可滚，迷你持仓始终在右栏可见（桌面）。
2. 选中任意候选：日 K 在中栏出现（非空白）；「详细 K 线」外链仍可用。
3. 无决策/无持仓：中下与右栏显示空态，不破坏栅格。
4. &lt;1100px：单列顺序正确，无横向溢出。
5. 既有 vitest：启停/加载 cockpit 仍通过。
